# SAPSA Custom Development and Architecture

Demos and supporting content for the SAPSA Focus Group on Custom Development and
Architecture. This repo is free for anyone in the group (or anyone else) to use,
adapt, and reuse.

## What's here

- `1. agentic-development/` — the Session 1 demo project (first in the series):
  - `1. agentic-development/.claude/skills/` — Claude Code skills used to build and operate the RAP demo.
  - `1. agentic-development/agentic-dev/` — the agentic development workspace, including
    `site-visit-log/`, a CAP/RAP "Site Visit Log" business application used as the
    running example throughout the session.

Future sessions will be added here as numbered sibling folders.
